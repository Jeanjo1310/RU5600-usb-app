Zona peligrosa

Un mal bloqueo deja el tag inservible para siempre y un comando crudo puede dejar el lector en un estado inconsistente.

A · Bloquear tag (Gen2, cmd 0x05)

B · Comando crudo (CFHid_SendCommand)

BLOQUEADOS: 0x2B/0x2C/0x2D (firmware) y 0x65 (Kill6C, mata un tag).

C · CryptWrite (experimental)

0x2F con payload [mode][0x55][pass]. Este firmware (7.1) no responde a 0x2E/0x2F: área en desarrollo.

Comandos conocidos del lector RU5600

0x01 inventario   0x02 leer memoria   0x03 escribir memoria   0x04 escribir EPC   0x05 lock   0x10 informacion   0x20/0x21 parametro   0x23/0x24 un parametro   0x3E/0x3F frecuencia   0x30 reiniciar   0x40/0x41 start/stop read   0x85/0x86 relay   0xE0 modulo   0xE1 antena   0xE8-0xEC whitelist   0x2E/0x2F CryptWrite
BLOQUEADOS: 0x2B/0x2C/0x2D (actualizan el firmware del lector) y 0x65 (Kill6C, mata un tag).
