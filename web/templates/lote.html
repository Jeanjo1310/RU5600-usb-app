Cambiar EPC según planilla

Para cambiar tags uno por uno: la columna A es el EPC que el tag tiene hoy y la columna B el que tiene que quedar. Se validan todas las filas antes de escribir; el resto de las columnas se ignora. Los tags que ya tienen el EPC nuevo se ignoran (no se reescriben) y la fila se marca como cumplida.
